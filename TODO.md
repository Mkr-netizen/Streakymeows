# Streaky Habit Tracker — outcomes

- [x] **Create and manage habits.** “I want to add habits with an emoji and colour.” Users can add habits with a name, emoji, and colour; edit or delete existing habits.
- [x] **Daily completion and streaks.** “check them off each day, see current and best streaks.” Users can check or uncheck each habit for the current day and see its current and best streak counts.
- [x] **Yearly progress view.** “a GitHub-style yearly heatmap for each habit.” Show a GitHub-style yearly completion heatmap for each habit.
- [x] **Weekly summary.** “a weekly summary.” Provide a weekly summary of habit completion and consistency.
- [x] **Delightful interaction and local persistence.** “Make it feel fun and satisfying to tick things off, with little animations. Save everything in the browser so it works without an account.” Add satisfying micro-animations and visual feedback when a habit is checked off. Persist habits and completion history in browser storage with no account required.
- [x] **Responsive mobile-ready web experience.** The requested product is a “habit tracker web app”; ensure the interface works comfortably on mobile and desktop while retaining local-only use.
